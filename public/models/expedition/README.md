- 模型底部为原点、归一化高度 1。沉船游戏尺寸约 18×5×3.2 米，Blender 实际切除中部货舱遮挡与右舷破口；运行时随当地曲面海床调整断裂船体，船锚贴合海床。
- 六只水母复用一个实例网格，范围内缓慢漂游，伞部和触手由游戏顶点着色器驱动。GLB 和 Blender 为静态休息姿态，没有离线骨骼动画。

- 靠近探索区 180 米内才请求模型，失败保留程序化船体和水母；不在港口启动时下载。
- 原始 GLB、服务 ZIP 与带贴图 Blender 工程保存在本机交付包。生成模型和贴图按 Aholo 服务条款使用；新增代码沿用项目 MIT 许可证。模型为游戏近似，水母夜间发光为艺术表现。
