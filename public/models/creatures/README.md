# 海洋生物模型

## 深海古神

`abyssal-elder.glb`：原创程序化八臂章鱼网格，Aholo Lux3D 任务 `4163910` 生成材质，本机 Blender 优化并添加 `_SOURCE` 顶点映射。

- 67,428 个三角面，完整嵌入颜色和粗糙度贴图；无外部图片依赖。
- `_SOURCE` 必须保留：运行时用它恢复真实海床位置、部位及 GPU 触手动画权重。
- Blender 工程及原始生成 GLB 保存在本机交付目录；处理命令见 `docs/深海古神模型.md`。
- 代码及原创几何体沿用项目 MIT 许可证；AI 生成材质按 Aholo 服务条款使用。无外部第三方章鱼模型或照片输入。

## 珊瑚礁海龟与鹰鳐

2026-10-17 经用户授权，直接调用 Aholo Lux3D 国内文本建模 API，各生成一次，再由本机 Blender 整理：

| 文件 | 物种 | 任务 ID | 游戏三角面 | 文件大小 |
|---|---|---|---:|---:|
| `green-turtle.glb` | 绿海龟（Chelonia mydas） | `4169673` | 11,899 | 2,297,964 字节 |
| `spotted-eagle-ray.glb` | 斑点鹰鳐（Aetobatus narinari） | `4169678` | 11,900 | 1,948,620 字节 |

- 每个模型为单节点、单材质，嵌入 1K 颜色及粗糙度贴图，保留原 UV 和顶点法线；没有外部图片依赖。服务未提供独立法线贴图。
- 海龟统一为鼻尖朝 +Z、背部朝 +Y、头尾长 1 单位；鹰鳐以翼展 1 单位匹配原模型，鼻尖在 +Z 0.5，尾巴向后延伸。
- 原生成鹰鳐有分叉尾，Blender 保留身体和斑点贴图，将分叉局部替换成单根渐细鞭尾；无额外付费重试。
- 运行时生成 `aData`，复用原鱼群的划鳍、摆翼与运动矢量。Blender 工程和 GLB 为静态休息姿态，动画由游戏着色器驱动。
- 保留原来的生态模拟与动物数量。24 米内首次尝试加载，12–20 米间渐变切换；远处或加载失败时显示原程序化模型。
- 生成模型和贴图按 Aholo 服务条款使用；新增代码沿用项目 MIT 许可证。

处理工具：`tools/prepare-swimmers.py`。原始 GLB、服务源包和带贴图 Blender 工程保存在本机 `outputs/reef-life` 及本任务源文件目录。
