# 海湾七号航程模型

2026-10-18，经用户直接调用 API 授权，通过 Aholo Lux3D 国内文本建模 API 生成四个模型，各提交一次，无付费重试。首批三个模型共 60 积分，按用户看到检查图后的要求追加船员 20 积分，合计 80 积分，账户权益抵扣前；报价不等于最终结算。

| 文件 | 内容 | 云任务 | 游戏三角面 | 大小 |
|---|---|---|---:|---:|
| station.glb | 海湾七号观测舱、太阳能板与天线 | 4178301 | 18,932 | 3,862,656 字节 |
| tender.glb | 海燕号补给小艇船体与舷外机 | 4178306 | 17,919 | 3,035,352 字节 |
| bell.glb | 带铜绿的旧船钟 | 4178310 | 6,420 | 2,582,276 字节 |
| crew.glb | 穿海员工作服、救生衣的写实成年男性（坐姿） | 4178542 | 19,720 | 6,013,608 字节 |

- F 盘 Blender 5.2.2 LTS 完成轴向、尺寸、减面和材质处理。每个模型为单节点、单材质，观测舱、小艇和船钟嵌入 1K 颜色及 ORM 贴图；船员保留 2K 颜色贴图以呈现五官，ORM 为 1K，无外部纹理链接；没有独立法线图。
- 原始观测舱屋顶中央敞开，Blender 用同一材质图集补上封闭顶板。四根海底支柱、精确平台、控制台与碰撞结构由游戏代码构建；在船上靠近南侧控制台操作，没有完整可进入室内。
- 模型底部为原点，高度归一化为 1。运行时观测舱约 3.6×3.2×4.8 米（含天线），小艇约 1.9×4.5×1.6 米，船员坐姿高 1.2 米，船钟高 0.48 米；收藏架上的船钟缩小陈列。
- 小艇、船员随事件一起起伏，使用真实海面高度查询和船舱遮水。写实船员替换原简化积木人物，按实际臀部和座板几何对齐，并增加脚踏板。船钟复用网格和材质，随起吊位置移动，打捞后跟随自己的船在收藏架陈列。GLB 与 Blender 工程是静态姿态，没有独立动画片段。
- 靠近观测站、补给事件或船钟时才请求对应模型（补给艇与船员一起加载）；请求复用，加载失败保留本地几何体和交互功能。
- 原始 GLB、服务 ZIP、带贴图 Blender 工程与实际检查图保存在本机交付包。生成模型和贴图按 Aholo 服务条款使用；新增代码沿用项目 MIT 许可证。没有输入第三方照片或模型。

复现：`tools/prepare-voyage.py`，依赖同目录已有的 `prepare-abyss-props.py` 和 `prepare-swimmers.py`。检查：`node test/voyage.mjs`；原生 WebGPU 检查：`node test/voyage.mjs --render --lux`。原生检查使用简化水面，不能代替浏览器完整交互和界面验收。

完整水体检查：`node test/voyage-ocean.mjs`。观测站平台抬高到海平面上方约 2.4 米，四桩仍接到真实海床；未添加室内行走。
