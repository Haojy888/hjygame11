# 沉睡古神 · 深渊巨章

位置由 `WORLD.abyss` 统一定义：`(-20, 海床高度, 440)`，主岛真实海床约深 22.44 米。远海解锁后，M 地图显示遗迹。它是幻想探索生物，当前没有战斗或捕捉规则。

## 模型与运行

- 八条连续卷曲的腕足，使用现有曲线与运输框架，避免竖直卷曲时突然扭转。
- 256 个中空吸盘，沿八条腕足双排布置；褶皱皮肤、乳突、水平瞳孔、额头发光沟纹。
- 巨章约 6.74 万个三角面、一个合并网格；九块遗迹石柱另一个合并网格。远离 190 米后整组隐藏。
- 触手与吸盘共享 GPU 变形权重，呼吸和摆动连续播放；运动向量同时考虑上一帧时间和苏醒程度。
- 腕足沿实际海床起伏生成；全部模型顶点保持在海面下。水下仍使用原游戏的消光、焦散、手电与雾。
- 靠近的潜水玩家会触发一次发现提示。返回水面或离开后逐渐恢复休眠；自由镜头不触发发现提示。

## Lux3D 写实材质

- 2026-10-17 使用 Aholo Lux3D 国内 API，对现有模型进行一次材质处理，任务 ID 为 `4163910`；未重新生成触手几何。
- 游戏资源为 `public/models/creatures/abyssal-elder.glb`，约 7.5 MB。原始生成文件约 11.6 MB；Blender 将颜色贴图整理为 1536²、粗糙度贴图整理为 1024²，并保留原模型的 67,428 个三角面。
- 加入橄榄棕皮肤、斑驳细节与粗糙度变化。游戏材质修正吸盘的肉色、虹膜的琥珀色，关闭生物皮肤金属度，保留克制的古痕发光。
- `_SOURCE` 顶点属性记录原网格索引。加载时逐顶点恢复真实海床上的坐标、法线、部位和触手权重；UV 接缝增加的顶点不会使吸盘与触手脱节。
- 首次进入遗迹 190 米范围时加载一次，港口启动不请求该资源。加载失败保留原模型，重复靠近不会重复请求。
- Blender 工程保留贴图及八个循环形态键。运行时使用相同触手权重的 GPU 动画，不读取形态键。

本机处理命令（输入为已下载的 Lux3D GLB）：

```powershell
& 'F:/Blender/blender-5.2.2-windows-x64/blender.exe' --background --python-exit-code 1 --python tools/prepare-deep-beast.py -- <Lux3D.glb> ../deep-beast/mesh.json ../deep-beast-lux3d
```

生成 `abyssal-elder-lux3d.glb`、`abyssal-elder-lux3d.blend` 与 `blender-preparation.json`。服务提供的原始 ZIP 下载链接过期且返回 403；已保留成功下载的完整 GLB，并由此保存带贴图的可编辑 Blender 工程，未为恢复下载重复付费生成。

## 生成可编辑模型

原版程序化模型仍作为加载前及失败时的回退。下面的命令导出原版，写实材质版使用上一节的处理脚本。

从仓库根目录运行：

```powershell
node tools/export-deep-beast.mjs ../deep-beast
& 'F:/Blender/blender-5.2.2-windows-x64/blender.exe' --background --python tools/deep-beast-blender.py -- ../deep-beast/mesh.json ../deep-beast
```

得到 `abyssal-elder.blend` 和 `abyssal-elder.glb`。源文件包含顶点色、部件材质、腕足权重和循环形态键预览；GLB 为 Y 轴朝上。游戏中的随机海床适配、水下光照与连续着色器动作以 JS / WGSL 为准。

## 验证与预览

```powershell
node test/deep-beast.mjs
node test/deep-beast.mjs --render
node test/deep-beast.mjs --ocean
node test/deep-beast.mjs --render --lux
node test/deep-beast.mjs --ocean --lux
```

默认检查几何有效性、真实地形、水下净空、苏醒、休眠、地图、远处隐藏、贴图与原始权重映射。预览命令使用本机原生 WebGPU 输出模型预览与海洋光照、手电、水下合成预览。原版文件保存在 `../deep-beast/`，带 `--lux` 的写实版保存在 `../deep-beast-lux3d/`。各预览命令单独运行。
